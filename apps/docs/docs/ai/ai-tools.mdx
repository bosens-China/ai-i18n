---
title: AI Agent 接入
description: 让 Agent 显式扫描、补齐并确认人工译文
---

ai-i18n 提供 `@ai-i18n/mcp` 和两份 Agent Skill：`integrate-ai-i18n` 用于项目接入，`use-ai-i18n-mcp` 用于扫描与补译。Codex 可通过项目插件安装它们；其他 Agent 可单独配置 MCP 和 Skill。

在目标 Vite 应用安装 `@ai-i18n/vite` 和 `@ai-i18n/mcp` 后，给 Agent 一个明确任务，例如：

> 扫描这个 Vite 应用，列出缺少的英文译文；给出建议后把我确认的译文写入人工文件。不要覆盖已有人工译文。

Agent 会找到目标应用，执行完整扫描、列出缺译，再按你的要求写入人工译文。写入 `*.manual.json` 后，需要重新扫描或构建才能更新最终 `locales/` 资源。

文件范围的 key 包含短文件标识，不用完整路径做资源 key。Agent 应编辑人工译文输入，不直接修改生成的 `locales/*.json`。适配器只在完整扫描和构建时调用；Agent 也可以把你确认的译文保存为人工值。

在 monorepo 中，先指定一个目标应用；不同应用各自拥有资源目录。Agent 可以分批列出缺译。未知 key、语言、占位符不匹配，以及未经允许覆盖已有人工值，都会被拒绝。

Codex 插件安装与版本选择以仓库当前插件清单为准；安装插件不会升级应用的 npm 依赖。应用集成方式见[快速上手](/guide/getting-started/vanilla)与[生成文件与 Git](/guide/basic/directory)。
