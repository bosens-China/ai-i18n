---
title: 异步翻译适配器
description: 在完整构建或显式扫描时接入自己的翻译服务
---

在 `ai-i18n.config.ts` 配置可选的 `adapter`。插件把本轮完整活动文案目录交给它；你可以请求翻译 API、读取外部资源，或者返回 `null` 不处理。

```ts
import { defineConfig } from '@ai-i18n/vite/config';

export default defineConfig({
  sourceLang: 'zh-CN',
  locales: [
    { value: 'zh-CN', label: '中文' },
    { value: 'en-US', label: 'English' },
  ],
  async adapter(catalog) {
    const translated = await yourTranslationService(catalog.messages);
    return {
      'en-US': Object.fromEntries(
        catalog.messages.map(({ key }) => [key, translated[key] ?? null]),
      ),
    };
  },
});
```

目录项包含 `key`、`source`、可选 `comment`、`scope`，文件范围还包含短标识与路径。返回值按目标语言与目录 key 索引，值为字符串或 `null`。省略的 key 或 `null` 表示缺译；空字符串是有效译文。未知语言、未知 key、非法值或模板占位符不一致会使本轮失败。

适配器只在 Build 和显式 MCP 扫描中调用，不在 Dev 自动运行。返回值不会被插件持久化为下一轮输入；如需复用外部结果，请自行存入你的服务。人工 `*.manual.json` 值始终优先。线上修改外部资源后需重新构建和部署；浏览器运行时不会自动从服务端覆盖资源。
