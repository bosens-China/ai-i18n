ai-i18n 通过 Vite 插件提取源码中的 `t()`，并向浏览器提供语言切换 Runtime。

## 安装

:::warning 环境要求

- 使用 Vite ≥ 8。
- Runtime 仅支持浏览器端，暂不支持 SSR。
- 每个 Vite build 只能使用一种框架模式：Vanilla、Vue 或 React。

:::

## 配置与使用

<Tabs>
  <Tab label="Vanilla">
    在 `vite.config.ts` 中注册 `aiI18n()`。没有检测到 Vue 或 React Vite 插件时，ai-i18n
    自动使用 Vanilla 模式。

    ```ts
    // vite.config.ts
    import { aiI18n } from '@ai-i18n/vite';
    import { defineConfig } from 'vite';

    export default defineConfig({
      plugins: [
        aiI18n({
          sourceLang: 'zh-CN', // 源码中直接书写的文案语言
          // value 用于 setLang() 与输出文件名，label 用于语言选择器展示。
          locales: [
            { value: 'zh-CN', label: '中文' },
            { value: 'en-US', label: 'English' },
          ],
        }),
      ],
    });
    ```

    从虚拟模块导入 Runtime API。Vanilla 模式需要在语言变化后主动更新 DOM：

    ```ts
    import { getLangs, setLang, subscribe, t } from 'virtual:ai-i18n';

    function render() {
      document.querySelector('#app')!.textContent = t('保存'); // 缺译时返回原文
    }

    render();
    subscribe(render); // 语言或翻译变化后重新渲染 DOM

    console.log(getLangs()); // 读取 vite.config.ts 中的 locales
    await setLang('en-US'); // 切换语言；按需加载时会等待语言包
    ```

  </Tab>

  <Tab label="Vue 3">
    保留项目现有的 `@vitejs/plugin-vue`。ai-i18n 会从最终的 Vite 插件列表识别 Vue 模式：

    ```ts
    // vite.config.ts
    import { aiI18n } from '@ai-i18n/vite';
    import vue from '@vitejs/plugin-vue';
    import { defineConfig } from 'vite';

    export default defineConfig({
      plugins: [
        aiI18n({
          sourceLang: 'zh-CN', // 源码中直接书写的文案语言
          // value 用于 setLang() 与输出文件名，label 用于语言选择器展示。
          locales: [
            { value: 'zh-CN', label: '中文' },
            { value: 'en-US', label: 'English' },
          ],
        }),
        vue(), // 保留 Vue SFC 编译，并让 ai-i18n 自动识别 Vue 模式
      ],
    });
    ```

    在组件中使用 `useI18n()`。语言变化后，使用这些响应式值的模板会自动更新：

    ```vue
    <script setup lang="ts">
    import { useI18n } from 'virtual:ai-i18n';

    const {
      currentLang, // 当前语言；在模板中会自动解包 readonly ref
      langs, // vite.config.ts 中配置的语言列表
      setLang, // 异步切换语言
      t, // 翻译源码文案，缺译时返回原文
    } = useI18n();
    </script>

    <template>
      <p>{{ t('保存') }}</p>
      <select :value="currentLang" @change="setLang(($event.target as HTMLSelectElement).value)">
        <option v-for="lang in langs" :key="lang.value" :value="lang.value">
          {{ lang.label }}
        </option>
      </select>
    </template>
    ```

  </Tab>

  <Tab label="React">
    保留项目现有的 React Vite 插件。ai-i18n 会从最终的插件列表识别 React 模式：

    ```ts
    // vite.config.ts
    import { aiI18n } from '@ai-i18n/vite';
    import react from '@vitejs/plugin-react';
    import { defineConfig } from 'vite';

    export default defineConfig({
      plugins: [
        aiI18n({
          sourceLang: 'zh-CN', // 源码中直接书写的文案语言
          // value 用于 setLang() 与输出文件名，label 用于语言选择器展示。
          locales: [
            { value: 'zh-CN', label: '中文' },
            { value: 'en-US', label: 'English' },
          ],
        }),
        react(), // 保留 JSX 转换，并让 ai-i18n 自动识别 React 模式
      ],
    });
    ```

    在组件中使用 `useI18n()`。语言变化后，组件会重新渲染：

    ```tsx
    import { useI18n } from 'virtual:ai-i18n';

    export function App() {
      const {
        currentLang, // 当前语言值
        langs, // vite.config.ts 中配置的语言列表
        setLang, // 异步切换语言
        t, // 翻译源码文案，缺译时返回原文
      } = useI18n();

      return (
        <>
          <p>{t('保存')}</p>
          <select
            value={currentLang}
            onChange={(event) => void setLang(event.target.value)}
          >
            {langs.map((lang) => (
              <option key={lang.value} value={lang.value}>
                {lang.label}
              </option>
            ))}
          </select>
        </>
      );
    }
    ```

  </Tab>
</Tabs>

运行 `vite dev` 并访问包含 `t()` 的页面后，插件会开始维护翻译文件。需要确认完整源码范围时，
再执行一次 `vite build`。
