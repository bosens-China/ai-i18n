---
title: 自动导入
description: 开启自动导入以免除手动引入 Hook 的繁琐，并了解它与 unplugin-auto-import 的配合方式
---

在业务代码中，通常需要频繁使用 `t` 或 `useI18n`。如果不希望每次都显式编写 `import { useI18n } from 'virtual:ai-i18n'`，你可以启用自动按需导入功能。

## 开启自动导入

你可以直接在配置中设置 `autoImport: true`：

```ts
// vite.config.ts
import { aiI18n } from '@ai-i18n/vite';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [
    aiI18n({
      // ... 其他基础配置
      autoImport: true,
    }),
  ],
});
```

一旦开启：

- 在 **Vanilla** 模式下，可以直接在全局使用 `t`, `setLang`, `getLang`, `getLangs`, `subscribe`。
- 在 **Vue** 与 **React** 模式下，可以直接在组件里使用 `useI18n()`。

## TypeScript 支持

插件默认在根目录的 `src/ai-i18n.d.ts` 声明虚拟模块和
`defineI18nMessages<T>(value)` 编译宏。开启自动导入后，同一文件还会声明当前框架模式下的
Runtime 全局 API，避免 IDE 报未定义错误。该文件由插件维护，带有 `@noformat` 等标记，
请勿手工编辑。

你可以通过 `dts` 选项调整生成行为：

```ts
aiI18n({
  autoImport: true,
  // 禁用自动生成
  // dts: false,
  // 或者自定义生成路径
  dts: 'types/ai-i18n-auto-imports.d.ts',
});
```

:::tip
声明文件会在首次启动 Vite 后生成。请将它纳入版本控制，并确保所在目录已被
`tsconfig.json` 的 `include` 字段包含。
:::

## 配合 unplugin-auto-import

许多项目已经使用了 [`unplugin-auto-import`](https://github.com/unplugin/unplugin-auto-import) 来自动导入 `vue`, `react` 相关的 API。

ai-i18n 可以与 `unplugin-auto-import` 同时使用。你**不需要**修改后者的 `imports` 列表。

ai-i18n 会读取 Vite 最终解析的插件列表，因此不依赖两者在 `plugins` 中的先后顺序：

```ts
import { aiI18n } from '@ai-i18n/vite';
import AutoImport from 'unplugin-auto-import/vite';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
  plugins: [
    aiI18n({
      // 检测到 AutoImport 时，ai-i18n 会开启自己的按需导入
      sourceLang: 'zh-CN',
    }),
    AutoImport({
      imports: ['vue'],
    }),
    vue(),
  ],
});
```

ai-i18n 会探测插件队列中的 `unplugin-auto-import`，并以此启用自己的导入注入和
Runtime 全局声明；`ai-i18n.d.ts` 本身无论是否自动导入都会生成。两个插件的处理管线和
声明文件相互独立。
