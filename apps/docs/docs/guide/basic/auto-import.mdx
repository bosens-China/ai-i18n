---
title: 自动导入
description: 显式开启 ai-i18n 自动导入，并配置对应的 TypeScript 与 ESLint 声明
---

自动导入默认关闭。未配置时，请从 `virtual:ai-i18n` 显式导入 Runtime API：

```ts
import { useI18n } from 'virtual:ai-i18n';
```

## 开启自动导入

如果希望省略这些 import，请显式设置 `autoImport: true`：

```ts
// vite.config.ts
import { aiI18n } from '@ai-i18n/vite';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [
    aiI18n({
      sourceLang: 'zh-CN', // 源码文案使用的语言
      locales: [
        // value 是语言标识，label 是界面中的展示名称。
        { value: 'zh-CN', label: '中文' },
        { value: 'en-US', label: 'English' },
      ],
      autoImport: true, // 按框架模式注入未绑定的 Runtime API
    }),
  ],
});
```

插件会根据最终框架模式注入对应 API：

| 模式    | 自动导入的 API                                     |
| ------- | -------------------------------------------------- |
| Vanilla | `t`、`setLang`、`getLang`、`getLangs`、`subscribe` |
| Vue     | `useI18n`                                          |
| React   | `useI18n`                                          |

插件只注入没有本地 binding 的调用。显式 import、局部变量或同名函数始终优先，不会被覆盖。
安装其他 Vite 插件不会自动开启该能力。

## TypeScript 支持

插件默认在根目录的 `src/ai-i18n.d.ts` 声明虚拟模块和
`defineI18nMessages<T>(value)` 编译宏。开启自动导入后，同一文件还会声明当前框架模式下的
Runtime 全局 API，避免 IDE 报未定义错误。该文件由插件维护，带有 `@noformat` 等标记，
请勿手工编辑。

你可以通过 `dts` 选项调整生成行为：

```ts
aiI18n({
  autoImport: true, // 同时为自动导入的 Runtime API 生成全局类型
  dts: 'types/ai-i18n-auto-imports.d.ts', // 修改声明文件的输出路径
  // dts: false, // 完全禁用生成；此时需要自行维护等价声明
});
```

:::tip
声明文件会在首次启动 Vite 后生成。请将它纳入版本控制，并确保所在目录已被
`tsconfig.json` 的 `include` 字段包含。
:::

## ESLint 配置

TypeScript 声明不会自动配置 ESLint。开启自动导入后，请按最终框架模式使用
`@ai-i18n/eslint-plugin` 的 `configs.vanilla`、`configs.vue` 或 `configs.react`。
这些预设会声明对应的只读全局，并检查静态提取语法。完整配置见
[ESLint](/guide/quality/eslint)。
