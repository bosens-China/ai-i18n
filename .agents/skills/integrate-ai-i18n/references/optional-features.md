# Agent defaults for optional features

Read this file only when the user explicitly requests an optional feature or the target build already
uses one. First locate the named documentation page through
`https://bosens-china.github.io/ai-i18n/llms.txt`; use this table only for Agent action defaults.

| Feature | Agent default | Documentation title in `llms.txt` |
| --- | --- | --- |
| Automatic imports | Keep explicit imports; enable only on request. Remove now-redundant explicit imports only within the requested integration scope. | 自动导入 |
| Automatic translation | Do not add or invoke a Provider unless requested. Copy Provider fields from the installed types and targeted public page; do not guess required credentials or model names. For `@ai-i18n/openai`, expose user preferences only through `style`; never restore or synthesize `systemPrompt`, JSON output rules, placeholder rules, or row-mapping instructions. Run one real Build when credentials are available so configuration, incremental batch input, and structured output validation are all exercised. | AI 翻译 |
| LLM audit logs | Preserve the current choice and default to disabled. Enable only when requested or already configured through `provider.logging`: `true` selects `<vite-root>/logs`, while a string selects a root-relative or absolute directory. Ensure that directory and `*.log` are ignored by Git. | LLM 日志与排障 |
| Dev timing diagnostics | Keep disabled unless the user requests Dev performance diagnosis. Prefer `diagnostics.timing: true` first; use `{ minDurationMs }` only when a different non-negative threshold is useful. Reproduce the slow navigation, compare the `source-transform` and `file-sync` totals, then use their ready/analysis/dependency/state/snapshot/extracted/Translation-Memory/locale sub-stages to attribute the slow total. Do not add nested totals together. A background `file-sync` log does not prove that navigation waited for it, and a browser 304 does not prove plugin time. `dependency-resolution` can include Vite `resolve()`, a full Dev Environment child transform or Build `load()`, so do not classify its full duration as plugin-only CPU or propose complex caching from one slow line. Current Dev embeds registration in the requested business module; auto-imported APIs and ordinary static named explicit imports share the internal Runtime. `virtual:ai-i18n/register?module=...` requests indicate an older package. Vue compile-time macro bindings, namespace/dynamic imports, direct re-exports, side-effect imports, and mixed type or unknown imports may still resolve a scoped Runtime module. Build virtual modules are bundled into business chunks; do not infer browser request count from module count. The plugin already merges its runtime entries into `optimizeDeps.exclude`; if Vite reports late optimization for other app dependencies, classify that separately and do not change the app's optimization policy without user scope. Node diagnostics can be fixed with `AI_I18N_DIAGNOSTIC_LOCALE`; browser Runtime warnings select one language from the browser time zone. Never concatenate Chinese and English into one diagnostic. Remove the option after diagnosis. | AiI18nDiagnosticsOptions |
| Language persistence | Do not add persistence unless requested; preserve an existing app-specific key. | AiI18nPersistOptions |
| Locale loading | Do not enable or reshape language chunks unless requested. | 语言分包与按需加载 |
| Translation Memory capacity | Do not set a size limit unless requested. When requested, configure `translationMemory.capacity`; do not confuse it with `provider.cache`, which controls one-process Provider refresh. | AiI18nTranslationMemoryCapacityOptions |
| Translation Memory | Keep project JSON, limits, cleanup, and Provider cache choices unless requested. Automatic translations always belong in committed `translations/` shards; human decisions belong in `overrides/`. | Translation Memory |
| SQLite Translation Memory | Add only when the user requests local cross-project reuse or the target already uses it. Install `@ai-i18n/sqlite`, import `sqlite`, and inject `translationMemory.cache: sqlite()`. Never add a storage marker, make SQLite authoritative, or add `better-sqlite3` directly to core/Vite. | Translation Memory |
| Dev Review | Do not register Review unless requested or already present. Add `aiI18nReview()` from `@ai-i18n/vite/review` beside `aiI18n()`; never use the removed `review` option. Keep the default page launcher and console URL unless the user requests `launcher: false` or `printUrl: false`; these options do not disable `/__ai-i18n/` or its API. | 翻译校对 |
| HTML extraction | Do not enable or broaden extracted attributes unless requested. | HtmlExtractorOptions |
| ESLint | Do not install or change presets unless requested. When enabled, verify at least one real translated source path, including aliases used by that path. Do not suppress or disable `no-embedded-markup` to make verification pass. Report warnings outside the requested edit scope, and follow the public rule reference for in-scope fixes. | ESLint / ESLint 规则参考 |
| Vitest | Do not add the adapter unless requested. If production `aiI18n()` causes the documented SSR warning in tests, use `aiI18nVitest()` instead of silencing it. Remove manual aliases and `vi.mock('virtual:ai-i18n')`; they replace the official test Runtime. If a translated array becomes a string or indexing returns one character, inspect shared test setup before changing application code. | 测试（Vitest） |

Do not enable adjacent features merely because they are shown on the same documentation page. After
editing, run the feature-specific validation recommended there.
